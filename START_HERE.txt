YASHASWINI STAY — QUICK START

1. Install Node.js and MySQL.
2. Open this folder in PowerShell.
3. Run: npm install
4. Execute database.sql in MySQL Workbench.
5. Copy .env.example to .env.
6. Edit .env and enter your MySQL password.
7. Choose a private ADMIN_EMAIL and ADMIN_PASSWORD in .env.
8. Run: npm start
9. Open: http://localhost:3000

Customer accounts are created by using Register. There is no fixed customer username/password.
Keep the PowerShell server window open while using the website.
See README.md for full instructions.
